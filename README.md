# budget-sn-plugin

Плагін-редактор «Бюджет» для [Standard Notes](https://standardnotes.com/): борги, накопичення, щомісячні надходження й витрати, план місяця. Мультивалютність без автоматичного перерахунку — сума у валюті плюс введена вручну сума в грн.

Дані зберігаються в нотатці **звичайним Markdown**, тож вона читається і без плагіна.

**Статус:** етап 2 — борги, накопичення, місяці, шаблон місяця, «Оплатити», зв'язки й «Огляд». Мобільна розкладка й діалоги — етап 3. Зразок нотатки — [`docs/SAMPLE.md`](docs/SAMPLE.md); результати перевірки платформи — [`docs/STAGE0.md`](docs/STAGE0.md).

- Технічне завдання: [`docs/SPEC.md`](docs/SPEC.md)
- Правила для Claude Code: [`CLAUDE.md`](CLAUDE.md)
- Нотатки з безпеки: [`docs/SECURITY-NOTES.md`](docs/SECURITY-NOTES.md)

## Приватність

Плагін не робить жодних мережевих запитів, не використовує сховища браузера і не логує вміст нотатки. Деталі — `docs/SPEC.md`, розділ 7.
